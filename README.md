# pcr-excel-axis-batch-tool
# pcr轴模板批量处理工具

一个带图形界面的 Excel 批量处理工具，用于自动排版和合并特定格式的“轴模板”工作表。主要功能包括定位表头、合并数据行、统一字体、追加标题后缀，以及根据秒数规则智能合并角色行（支持富文本颜色和字体保留）。

## 环境要求

- Python 3.8 或更高版本（推荐 3.10+）
- 操作系统：Windows（图形界面基于 tkinter）

## 依赖库

需要安装以下第三方库：

```bash
pip install openpyxl wcwidth
```

`tkinter` 为标准库，无需额外安装。如果 Python 环境中缺少 `tkinter`，请参考官方文档补全安装。

## 使用方法

1. 下载代码到本地。
2. 安装依赖：
   ```bash
   pip install openpyxl wcwidth
   ```
3. 运行脚本：
   ```bash
   python main.py
   ```
4. 在打开的图形界面中：
   - 点击“添加文件”选择单个或多个 Excel 文件（`.xlsx`），或点击“添加文件夹”批量导入。
   - 可选：勾选“在轴标题末尾追加文字”并编辑后缀，默认后缀为 ` by 筱娅`。
   - 点击“开始处理”。
5. 处理成功后，会在原文件相同目录下生成以“已抄轴_”为前缀的新文件。

## 表格要求

- Excel 文件中必须包含名为 **轴模板** 的工作表。
- 前 30 行内必须存在一行表头，依次为：`秒数`、`角色`、`操作`、`操作`、`操作`、`伤害`（后两列允许为空或“操作”）。
- 数据行从表头下方开始，直到“角色”列为空时结束。
- 表格中可能存在宽合并单元格（合并列数大于 5），工具会自动跳过这些行，保留其原始格式。

## 功能说明

1. **表头处理**：将“角色”至“伤害”的 5 格合并居中，填入“角色”。
2. **数据行填充**：
   - 根据“操作”列内容，在角色名后添加 `(AUTO)` 或 `(操作名)`，并设置颜色（AUTO 为蓝色，其他操作为红色）。
   - 无操作或“连点”时仅显示角色名，黑色。
3. **统一字体**：将所有单元格字体设为“汉仪文黑-65W”（保留原有字号、斜体等其他属性）。
4. **取消加粗**：B1 和 C1 单元格强制取消加粗。
5. **标题后缀**：可选项，在 C1 原内容末尾追加自定义文字。
6. **智能行合并**：
   - 合并相邻角色行，总显示宽度不超过 36 个半角字符。
   - 相同秒数连续行视为一个整体，捆绑参与合并。
   - 秒数变化时，在新的组合首位角色后添加格式化的秒数标签（如 `(119)`、`(052)`），格式为去掉冒号并补齐三位。
   - 保留合并前的富文本颜色和字体。

## 注意事项

- 运行程序需要系统安装“汉仪文黑-65W”字体，否则 Excel 打开生成的文件时可能使用默认字体替代。可在代码中修改字体名称以适配其他字体。
- 程序会自动跳过合并单元格宽度超过 5 列的行，避免破坏原有表格结构。
- 若 `wcwidth` 库未安装，程序会使用简化的宽度估算（中文字符计为 2，英文计为 1），可能导致宽度判断不精确，建议务必安装。
- 生成的新文件会自动添加“已抄轴_”前缀，多次处理时会覆盖同名文件，请注意备份。

## 打包为 EXE

可以使用 `build.bat`（参考提供的打包脚本）配合 PyInstaller 将脚本打包为独立可执行文件。打包时无需包含字体文件，因为字体名称已硬编码，实际显示依赖系统字体。
