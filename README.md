# PCR 轴模板批量处理工具

带图形界面的 Excel 批量处理工具，用于自动排版和合并特定格式的"轴模板"工作表。支持双模板切换、富文本着色、智能行分组，UI 采用现代扁平风格设计。

## 项目结构

```
pcr-excel-axis-batch-tool/
├── main.py          # 主入口，GUI 界面与流程调度
├── templates.py     # 处理模板定义与执行逻辑
├── ui_config.py     # 统一样式配置（配色 / 字体 / 间距）
├── build.bat        # PyInstaller 打包脚本
└── README.md
```

## 环境要求

- Python 3.8 或更高版本（推荐 3.10+）
- 操作系统：Windows（图形界面基于 tkinter）

## 快速开始

```bash
# 1. 安装依赖
pip install openpyxl wcwidth

# 2. 运行程序
python main.py
```

依赖说明：
| 库 | 用途 |
|---|---|
| `openpyxl` | Excel .xlsx 读写 |
| `wcwidth` | 精确计算中日韩字符显示宽度 |
| `tkinter` | 标准库，无需安装 |

## 使用流程

1. 点击「添加文件」选择单个或多个 `.xlsx` 文件，或「添加文件夹」批量导入
2. 在「处理模板」卡片中选择处理模式，点击「显示详细说明」查看完整步骤
3. 可选：勾选「在轴标题末尾追加文字」，编辑后缀内容（默认 ` by 筱娅`）
4. 点击「开始处理」
5. 处理完成后，原文件同目录下生成 `已抄轴_原文件名.xlsx`

## 表格要求

- Excel 文件必须包含名为 **轴模板** 的工作表
- 前 30 行内存在表头行：`秒数｜角色｜操作｜操作｜操作｜伤害`（后两列可为空）
- 数据从表头下一行开始，直到"角色"列为空结束
- 宽合并单元格（>5 列）会被自动跳过

## 处理模板

### 模板 1 — 标准处理（默认）

完整流程，共 7 个步骤：

1. **查找表头** — 在前 30 行定位 `秒数｜角色｜操作｜操作｜操作｜伤害`
2. **表头处理** — 将「角色」至「伤害」5 列合并居中，填入「角色」
3. **逐行处理** — 读取操作列，生成富文本：
   - 空 / "连点" → 黑色角色名
   - "AUTO" → 蓝色 `角色名(AUTO)`
   - 其他 → 红色 `角色名(操作名)`
4. **字体替换** — 全部单元格设为「汉仪文黑-65W」，保留字号和颜色
5. **格式化** — B1/C1 取消加粗；可选追加标题后缀
6. **智能分组** — 相同秒数相邻行合并为一行，用 `-` 分隔，超宽自动截断
7. **保存输出** — 生成 `已抄轴_原文件名.xlsx`

### 模板 2 — 简化处理

与模板 1 的前 5 步完全相同，**不执行第 6 步智能行分组合并**。每行数据保持独立，适合需要保留原始行结构的场景。

## UI 设计

- **配色**：主色 `#4A90D9`（蓝），强调色 `#FF6B6B`（红），背景 `#F0F2F5`（浅灰）
- **版面**：卡片式分区，标题 → 文件列表 → 模板选择 → 选项 → 日志
- **字体**：界面使用 Microsoft YaHei，日志区 Consolas 等宽字体
- **响应式**：窗口可自由缩放，文件列表和日志区自动伸缩
- **模板描述**：默认收起，点击「显示详细说明」展开完整步骤

## 打包

```bash
build.bat          # 使用 PyInstaller 打包为独立 .exe
```

打包时字体名称已硬编码，实际显示依赖系统安装的「汉仪文黑-65W」。

## 注意事项

- 系统建议安装「汉仪文黑-65W」字体，否则 Excel 打开生成文件时可能使用默认字体
- 多次处理同一文件会覆盖已生成的 `已抄轴_` 前缀文件，请注意备份
- `wcwidth` 未安装时程序使用简化宽度估算（中文=2，英文=1），建议安装以获得精确判断
